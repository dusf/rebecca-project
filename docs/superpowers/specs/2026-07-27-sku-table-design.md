# 添加产品页 SKU 列表设计

## 目标

优化商城后台添加产品页的 SKU 列表，使运营人员能在约 716px 的实际表格可视宽度内优先维护 SKU 基础信息，并支持未来持续增加的多仓库存字段。

## 当前约束

- 页面内容容器实测约 1100px。
- 左侧 SKU 卡片实测约 760px。
- 扣除卡片内边距后，SKU 表格可视宽度实测约 716px。
- 页面仍保持左右两栏结构，不通过扩大页面或占满浏览器宽度解决表格问题。
- 当前阶段为静态前端原型，不接入真实仓库接口。

## 表头与列顺序

采用两级表头，分为四个字段组：

1. `SKU 识别`
2. `销售设置`
3. `库存配置`
4. `仓库库存`

从左到右的列顺序为：

1. 行选择框（工具列，不计入业务列）
2. 图片
3. SKU 名称（英语）
4. 价格（美元）
5. 断货继续销售
6. 库存 SKU 编码
7. 库存联动
8. 购买基数
9. 可售合计
10. 动态仓库库存列

图片、SKU 名称（英语）、价格（美元）是前三个业务列。`断货继续销售` 紧随价格列，宽度约 96px。

两级表头分组与列的对应关系：

- `SKU 识别`：图片、SKU 名称（英语）
- `销售设置`：价格（美元）、断货继续销售
- `库存配置`：库存 SKU 编码、库存联动、购买基数、可售合计
- `仓库库存`：动态仓库库存列

## 宽度与滚动

- 外层 SKU 卡片宽度保持现状，不随浏览器宽度继续拉伸。
- 表格可视区域占满当前卡片，约 716px。
- 内部表格使用约 1200–1400px 的最小宽度，并在表格容器内部横向滚动。
- 仅行选择框、图片和 SKU 名称（英语）保持紧凑冻结。
- 价格、断货继续销售、库存配置和仓库库存均随表格横向滚动。
- 冻结边界与 `SKU 识别` 分组边界保持一致，避免跨列表头出现一半固定、一半滚动。
- 冻结区域与可滚动区域之间使用轻微阴影区分。
- 表头与表体保持同一水平滚动位置。

## 动态仓库列

- 仓库库存列由仓库配置动态生成，仓库数量不设 1–3 个上限。
- 默认展示当前店铺的常用仓库。
- 提供 `显示仓库 N / M` 控件，用于选择当前显示的仓库列。
- 隐藏仓库只影响页面展示，不影响已保存库存数据。
- `可售合计` 汇总当前 SKU 的全部仓库可售库存，而不是仅汇总当前可见仓库。

## 库存联动

库存联动同时提供批量操作按钮和 SKU 行级控制，不提供影响全部 SKU 的全局勾选开关。

### 批量库存联动按钮

- SKU 批量操作栏增加 `批量库存联动`下拉按钮。
- 下拉菜单提供 `开启库存联动`和`关闭库存联动`。
- 未选择 SKU 时按钮禁用。
- 批量操作只影响当前已勾选的 SKU，不影响未选择的 SKU。
- 批量开启后，所选 SKU 的仓库库存立即变为只读。
- 批量关闭后，所选 SKU 的仓库库存立即变为可编辑输入框。
- 不显示全选、全不选或半选状态的库存联动总控。
- 新生成 SKU 默认关闭库存联动，避免在库存 SKU 编码未配置时意外联动。

### SKU 行级控制

- 每个 SKU 独立维护 `库存联动` 勾选项。
- SKU 开启库存联动时，仅该行仓库库存只读并从库存系统模拟同步。
- SKU 关闭库存联动时，仅该行仓库库存切换为可编辑输入框。
- 同一张 SKU 表允许同时存在联动 SKU 和手动库存 SKU。
- `库存联动`与`断货继续销售`互相独立。
- 行级勾选项与批量按钮修改的是同一个 `stockLinked`状态。

### SKU 联动开启

- 各仓库库存来自库存系统模拟数据。
- 仓库库存单元格只读。
- `可售合计`只读并自动汇总。
- 该 SKU 不参与批量库存操作。

### SKU 联动关闭

- 当前显示的仓库库存单元格切换为数字输入框。
- 支持逐 SKU、逐仓库手动输入库存。
- 支持批量选择 SKU 后，同时选择多个目标仓库，并为每个仓库分别填写要设置的库存数。
- 手动修改但尚未保存的库存单元格使用轻量橙色状态提示。
- `可售合计`根据全部仓库库存即时重新计算。

## 断货继续销售

- 每个 SKU 独立维护 `断货继续销售` 勾选项。
- 勾选表示该 SKU 库存为 0 时仍允许继续销售。
- 未勾选表示该 SKU 库存为 0 时停止销售。
- 新生成 SKU 默认不勾选，避免意外超卖。
- 批量操作栏增加 `批量设置继续销售`，可统一勾选或取消选中 SKU。
- 勾选项必须可通过键盘聚焦和切换，并提供明确的可访问名称。

## 数据结构

每个 SKU 原型数据增加：

```text
continueSellingWhenOutOfStock: boolean
stockLinked: boolean
warehouseStocks: Record<warehouseId, number>
```

保留现有字段：

```text
name
img
invCode
qty
price
```

`stock` 作为兼容字段保留时，应由 `warehouseStocks` 汇总生成，不作为多个仓库库存的独立人工录入来源。

## 批量操作

批量操作栏保留：

- 批量图片
- 批量名称
- 批量库存编码
- 批量基数
- 批量价格

新增：

- 批量设置继续销售
- 批量设置库存联动
- 批量设置仓库库存

批量设置仓库库存时，通过任务型右侧抽屉搜索并多选目标仓库，每个已选仓库分别填写“设置为多少”。
批量库存不提供增加、减少、立即同步或关闭联动操作。
同一仓库填写的库存数统一应用到全部已关闭库存联动的选中 SKU。
批量设置仓库库存仅作用于已关闭库存联动的选中 SKU；已开启联动的 SKU 保持只读并在抽屉中提示跳过数量。
提交前显示 `可修改 SKU 数 × 已选仓库数`和总更新项数。

## 状态与边界

- 无仓库：仓库库存分组显示空状态 `暂未配置仓库`。
- 仓库较多：通过显示仓库控制和内部横向滚动处理，不扩大页面。
- 库存联动开启但无同步数据：单元格显示 `--`，并保留只读状态。
- 手动库存输入不得小于 0；无效值行内提示。
- 切换库存联动前，如存在未保存手动库存，需提示用户确认。
- SKU 重新生成时，应保留键值相同 SKU 的继续销售设置、库存联动状态和仓库库存。

## 实施范围

- 修改 `admin/product/add_product.html` 的 SKU 表头、列顺序、样式和前端原型交互。
- 保持页面整体布局、右侧栏、规格生成逻辑和其他表单区域不变。
- 不接入真实仓库 API、数据库或权限逻辑。

- 验证仅行选择框、图片和 SKU 名称在横向滚动后保持可见。

- 验证批量开启或关闭库存联动只影响当前已选择的 SKU。
- 验证新生成 SKU 默认关闭库存联动。
- 验证单个 SKU 开启库存联动时仅该行仓库库存只读。
