# 用户管理 Shopify 对话框对齐设计

## 目标

将用户管理“从 Shopify 导入用户”的三步对话框调整为产品列表“从 Shopify 拉取”对话框的尺寸、外框、留白和步骤指示器样式，同时保留用户导入独有的授权边界、店铺连接、客户档案筛选和导入规则。

## 影响范围

- 仅调整 `data-user-dialog="shopify"` 对话框。
- 不改变 CSV 导入、邮件营销、批量标签和删除对话框。
- 不改变 Shopify 单店授权、已连接店铺选择、客户筛选、跨筛选选择、导入和结果处理逻辑。

## 桌面端规格

- 对话框宽度为 `720px`，最大宽度为 `94vw`。
- 对话框固定高度为 `660px`，小视口时不超过视口减去 `48px`；步骤切换不改变外框高度。
- 外框使用系统卡片背景、`16px` 圆角和产品对话框同级阴影。
- 内容整体采用产品对话框的 `24px 24px 16px` 留白节奏。
- 标题为 `18px/700`；关闭按钮尺寸、图标和悬停状态对齐产品对话框。
- 标题区不显示当前用户对话框的整行底部分割线。
- 正文区域独立滚动，底部操作区保持可见。

## 分步指示器

- 放置在标题区下方、正文内容上方，与产品 Shopify 对话框位置一致。
- 指示器水平居中，上下各有一条分割线。
- 容器内边距为 `16px 20px`，与后续正文保持 `24px` 间距。
- 三个步骤分别为“选择店铺、选择用户、导入结果”。
- 当前步骤使用主题色实心圆；已完成步骤使用绿色圆形勾选；未开始步骤使用边框圆。
- 步骤之间使用连接线，已完成连接线显示绿色。

## 内容与操作区

- “选择已连接店铺”继续展示本系统中分别完成授权的店铺，不暗示通过一个域名发现多家店。
- “连接新店铺”继续进入单店 OAuth 模拟视图。
- 用户档案筛选、全选、列表和营销状态中文映射保持不变。
- 底部操作按钮使用产品对话框的紧凑排列和按钮高度；左侧“连接新店铺/上一步”语义保持不变。

## 响应式与可访问性

- 小于等于 `600px` 时，步骤数字缩小为 `22px`，标签为 `10px`，连接线缩短。
- 对话框保持父页面级全屏遮罩、焦点锁定、Escape 关闭和关闭后焦点恢复。
- DOM 中保留 `role="dialog"`、`aria-modal`、标题关联、按钮禁用状态和选择状态语义。

## 验收

1. Shopify 对话框桌面端宽度和视觉密度与产品列表 Shopify 对话框一致。
2. 三个步骤切换时对话框外框高度不跳动。
3. 步骤条固定出现在标题下、正文前，完成态、当前态和连接线状态正确。
4. 店铺选择、连接新店、客户筛选、选择、导入和结果流程仍可操作。
5. CSV、营销、批量标签和删除对话框样式不受影响。
6. 用户模块现有五组测试、JavaScript 语法、静态契约和预览资源检查通过。
