# 用户列表营销、标签与导出交互设计

## 背景

添加用户表单已经将营销同意拆分为电子邮件、短信和 WhatsApp 三个渠道，因此用户列表原有“邮件营销”批量操作无法完整表达当前数据模型。列表同时缺少单个用户添加标签的入口，批量账号状态菜单受表格层叠上下文影响会被列表覆盖，顶部导出操作也缺少范围与字段选择。

## 设计目标

- 让批量营销操作覆盖三个营销渠道，并保持电子邮件既有授权历史规则。
- 为单个用户补充添加标签入口，复用现有标签能力。
- 让账号状态及其他列表菜单始终显示在表格上方。
- 将导出拆成明确的范围选择和字段选择，避免误导出或字段冗余。
- 继续复用用户列表、产品列表和现有全屏对话框的视觉与交互规范。

## 方案

### 1. 批量营销授权

批量操作栏的“邮件营销”改为“营销授权”。点击后打开现有父页面全屏对话框，新增营销渠道选择：

- 电子邮件
- 短信
- WhatsApp

电子邮件继续使用 `已订阅 / 已退订 / 未订阅` 状态；选择“已订阅”时必须填写同意来源和同意时间，并继续写入现有电子邮件授权历史。

短信和 WhatsApp 使用 `已同意 / 未同意` 两种状态，更新用户档案中的对应渠道值。渠道切换时，弹窗文案和状态选项同步变化，避免把短信或 WhatsApp 误称为邮件订阅。

批量操作完成后刷新当前店铺用户列表并清除选择。

### 2. 单个用户添加标签

单行“更多操作”菜单增加“添加标签”，位置放在“复制邮箱”之后、“账号状态”之前。点击后复用现有标签对话框，并根据数量调整标题：

- 单个用户：`为用户添加标签`
- 多个用户：`为所选用户添加标签`

标签长度、去重和成功反馈继续使用现有规则。

### 3. 账号状态菜单遮挡修复

根因是当前视口浮层机制只覆盖自定义列和单行更多菜单，批量账号状态菜单仍留在批量栏自身的层叠上下文中，因此会被表格区域覆盖。

账号状态菜单加入统一的视口浮层机制：打开时将菜单面板临时挂载到 `body`，根据触发按钮的视口坐标定位，使用与产品列表一致的顶层层级；关闭、滚动或窗口尺寸变化时恢复原位置并清理行内定位。

该机制同时供顶部导出菜单复用，避免新增同类层级问题。

### 4. 导出范围菜单

顶部“导出用户”改为与“导入用户”一致的下拉按钮，包含三个范围：

1. `导出选中用户`：导出当前已勾选的用户；没有选择时禁用。
2. `导出当前查询结果`：导出当前 Tab、关键词、下拉筛选和日期条件匹配的全部结果，不受当前分页限制。
3. `导出全部用户`：导出当前店铺的全部用户。

批量操作栏现有“导出所选”删除，避免与顶部范围菜单重复。

没有可导出数据的范围显示禁用状态；菜单项同时显示对应数量，帮助用户在进入下一步前确认范围。

### 5. 导出字段对话框

选择导出范围后打开父页面全屏对话框，标题为“导出用户”，副标题显示导出范围和用户数量。

字段默认全部选中，支持逐项勾选、全选和清空。至少选择一个字段后才能点击“导出 CSV”。

可选字段：

- 客户编号
- 姓名
- 邮箱
- 手机号
- 标签
- 账号状态
- 电子邮件营销
- 短信营销
- WhatsApp 营销
- 登录方式
- 用户来源
- 订单数
- 累计消费
- 最后登录时间
- 创建时间

不导出内部主键、店铺内部标识、外部授权 ID 和授权历史明细。导出文件继续使用 CSV，并保留现有公式注入防护。

### 6. 数据与接口

用户存储层新增按渠道更新营销授权的方法：

- `email` 继续转交现有邮件营销状态与授权历史逻辑。
- `sms` 和 `whatsapp` 更新 `marketingChannels` 中对应布尔值。

用户页面向父页面对话框提供：

- 根据导出范围读取用户数据的能力。
- 根据字段列表生成并下载 CSV 的能力。
- 单个或批量添加标签的既有能力。
- 按渠道更新营销授权的能力。

导出对话框只负责范围说明、字段选择和提交，不直接读取用户存储，保持与现有父页面对话框架构一致。

## 状态与可访问性

- 无选择时，“导出选中用户”和需要选择的批量操作保持禁用。
- 无查询结果或无全部用户时，对应导出范围禁用。
- 菜单支持键盘聚焦、Escape 关闭和点击外部关闭。
- 对话框保持焦点约束、关闭后恢复触发按钮焦点。
- 字段复选框提供明确标签、选中状态和可见焦点。
- 导出处理中按钮显示“正在导出…”，失败保留弹窗并显示错误，成功后关闭弹窗并显示导出数量。

## 视觉规范

- 顶部导出菜单直接复用导入菜单的按钮高度、字号、下拉图标、圆角、边框、阴影和菜单项规格。
- 批量“营销授权”和账号状态继续使用折扣列表的批量按钮规格。
- 浮层使用产品列表的视口定位和层级。
- 导出字段对话框复用用户管理现有紧凑型对话框、14px 字段文字和自绘复选框。

## 验收标准

- 批量营销可以分别更新电子邮件、短信和 WhatsApp，文案不会混用渠道。
- 单行更多菜单可以为一个用户添加标签。
- 批量账号状态菜单不会被表格、固定列或滚动容器覆盖。
- 顶部导出菜单只包含选中、当前查询结果、全部三种范围。
- 当前查询结果导出覆盖所有匹配结果而非仅当前页。
- 导出字段默认全选，支持自定义，未选择字段时不能导出。
- 导出的 CSV 字段顺序与用户选择顺序一致，并保留公式注入防护。
- 受影响页面的按钮、菜单、对话框、字号、图标和层级与既有参考页面一致。
