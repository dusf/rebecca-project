# 自定义列弹层统一设计

## 目标

统一产品列表与用户管理的自定义列弹层，使用户管理直接采用产品列表的视觉规格和字段行结构，同时把两个页面的“恢复默认”统一放到弹层标题栏右上角。

本次只调整自定义列弹层，不修改表格字段业务、筛选、分页、客户编号或其他列表功能。

## 统一结构

两个页面的弹层内部统一为三段：

1. 标题栏：左侧“选择显示列”，右侧“恢复默认”文字按钮。
2. 辅助提示：说明拖拽排序和固定列。
3. 字段列表：拖拽手柄、显示勾选框、字段名称。

产品列表移除底部独立 footer，“恢复默认”移动到标题栏右上角。用户管理删除每行后面的上移、下移图标。

## 视觉规格

以产品列表当前样式为基准：

- 弹层宽度 `240px`。
- 白色背景、`10px` 圆角、系统边框和产品列表现有阴影。
- 标题与字段名称使用 `13px`。
- 标题字重 `600`。
- “恢复默认”使用 `12px` 主色文字按钮。
- 提示文案使用 `12px` 次要文字色和紧凑行高。
- 字段行沿用产品列表的水平布局、间距、hover、拖拽状态和 `16px` 勾选框。
- 可拖动字段显示产品列表现有 `⋮⋮` 拖拽手柄。
- 固定字段保持选中、禁用、不可拖动的弱化状态。

产品列表与用户管理共用 `admin/common/css/commons.css` 中的弹层内部样式。用户管理只保留外层定位和视口浮层所需的页面私有规则，避免复制一套相近但会继续漂移的字段样式。

## 提示文案

产品列表：

> 拖拽字段调整列顺序。产品信息始终固定在左侧。

用户管理：

> 拖拽字段调整列顺序。用户信息始终固定在左侧。

因为可见的上移、下移图标会被删除，提示文案不能继续写“或使用箭头调整列顺序”。

## 交互

- 点击勾选框继续控制字段显示和隐藏。
- 拖拽字段继续改变字段顺序并保存现有本地偏好。
- 用户信息和产品信息继续固定在左侧，不可隐藏、不可拖动。
- 点击“恢复默认”恢复默认显示列及默认排序，弹层保持打开，方便用户立即查看结果。
- 产品列表和用户管理继续使用各自已有的顶层挂载或视口定位逻辑，避免弹层被表格裁剪。
- 移除可见的上移、下移图标后，拖拽手柄应可获得键盘焦点；聚焦时允许使用 `ArrowUp`、`ArrowDown` 调整非固定字段顺序，但不显示额外箭头图标。
- 固定字段的拖拽手柄不可聚焦，并提供固定列不可移动的可访问说明。

## 实现边界

- `admin/common/css/commons.css`：补齐共享标题栏、恢复按钮、提示文案和字段列表样式。
- `admin/product/product_list.html`：移动恢复按钮、增加产品提示文案、移除 footer。
- `admin/common/js/commons.js`：为产品字段拖拽手柄补齐键盘排序和重新渲染后的事件绑定。
- `admin/user/js/users.js`：输出共享字段行结构、移除上下移动按钮、保留拖拽及增加拖拽手柄键盘排序。
- `admin/user/css/users.css`：删除不再使用的用户私有字段行和移动按钮样式，只保留用户弹层外层定位差异。
- 资源查询版本同步递增，避免浏览器继续使用旧 CSS 或 JavaScript。

## 验证

- 两个页面标题左侧均为“选择显示列”，右侧均为“恢复默认”。
- 两个页面均显示各自固定列提示。
- 用户管理不再渲染上移、下移按钮或图标。
- 两个页面的弹层宽度、标题字号、字段字号、字段行结构和勾选框规格一致。
- 鼠标拖拽、键盘上下移动、字段显隐和恢复默认均正常。
- 固定列不可隐藏、不可移动。
- 弹层不被表格或固定列遮挡。
- 用户管理现有五套测试、相关 JavaScript 语法检查、静态契约和页面资源检查通过。
