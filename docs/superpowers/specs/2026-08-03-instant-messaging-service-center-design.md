# 即时通讯服务商连接中心与买家端挂载设计

## 目标

将即时通讯从少量服务商卡片选择升级为可容纳十余家服务商的连接中心。商家可连接多家服务商，但买家端同一时刻仅启用一家；买家端入口可选择全站悬浮或装修页内嵌区块，两种模式互斥。

## 信息架构

1. **当前启用服务商**：固定摘要展示服务商、连接验证状态、最近验证时间与“管理”入口；没有启用服务商时明确显示未启用。
2. **服务商连接中心**：搜索和紧凑列表展示服务商、状态、验证时间与操作。状态包含当前启用、已连接、未连接、即将支持。连接与启用是两件事。
3. **连接详情**：针对列表中当前管理的服务商展示真实接入字段：客服工作区、Web 渠道 ID、买家端公钥、已授权域名，并提供验证配置、设为当前启用和断开连接。
4. **买家端挂载**：
   - 全站悬浮入口：配置左右位置、设备范围和文案。
   - 装修页内嵌区块：配置首页、商品详情页或自定义页面范围；装修页未来在“应用区块 > 即时通讯”中放置区块。
   - 两种模式互斥；本原型只保存挂载配置和预览，不允许粘贴脚本。

## 数据模型

```js
{
  provider: 'jishi' | 'salesmartly' | '',
  connections: {
    jishi: { connected: true, workspace: '', widgetId: '', publicKey: '', allowedDomain: '', verifiedAt: '' },
    salesmartly: { connected: false, workspace: '', widgetId: '', publicKey: '', allowedDomain: '', verifiedAt: '' }
  },
  display: {
    enabled: false,
    mode: 'floating' | 'inline',
    position: 'right' | 'left',
    desktop: true,
    mobile: true,
    pageScopes: ['home'],
    launcherText: '在线咨询'
  }
}
```

未来服务端将为每个受支持服务商维护独立的密钥映射，前端只读取脱敏状态。买家端由服务端在服务商已验证、已启用、设备与页面范围匹配时异步注入官方 SDK。

## 原型边界

- 不调用第三方 API，不加载 SDK，不允许粘贴任何脚本。
- 当前仓库没有店铺装修器；配置页使用“装修页应用区块”说明与内嵌预览表达未来挂载点，不修改内容富文本编辑器。
- 服务商列表展示十个容量示例，但本期可配置的服务商保持及时语和 Salesmartly；其他项显示即将支持。
