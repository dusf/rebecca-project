# 添加产品页批量库存设计

## 目标

为添加产品页 SKU 列表提供可扩展的批量库存设置能力，解决一个 SKU 对应多个仓库、仓库数量持续增加时的批量录入问题。

批量库存只处理未开启库存联动的 SKU。库存联动 SKU 的仓库库存保持只读，不提供同步、增加、减少或直接修改库存的操作。

## 适用范围

- 页面：`admin/product/add_product.html`
- 入口：SKU 列表批量操作栏中的 `批量库存`
- 数据范围：当前已勾选且未开启库存联动的 SKU
- 当前阶段：静态前端原型和模拟数据，不接入真实库存 API

## 库存联动边界

- 库存联动通过批量操作栏的 `批量库存联动`下拉按钮和 SKU 行级联动勾选项维护。
- 批量库存联动菜单提供 `开启库存联动`和`关闭库存联动`，只作用于当前已选择的 SKU。
- 开启库存联动的 SKU，其全部仓库库存输入框只读。
- 关闭库存联动的 SKU，其全部仓库库存输入框可编辑。
- 批量库存抽屉不提供立即同步库存、开启或关闭联动、跳转库存系统等联动操作。
- 批量库存提交时不得修改任何开启库存联动的 SKU。

## 按钮状态

- 未选择 SKU 时，`批量库存`按钮禁用。
- 所选 SKU 全部开启库存联动时，`批量库存`按钮禁用。
- 所选 SKU 中至少有一个未开启库存联动时，`批量库存`按钮可点击。
- 混合选择联动和非联动 SKU 时，抽屉只处理非联动 SKU，并明确显示跳过的联动 SKU 数量。

## 抽屉结构

点击 `批量库存`后，从页面右侧打开宽度约 720–760px 的任务型抽屉。

### 删除现有无效控件

- 当前内联批量库存区域中，仓库下拉前出现的 `请选择`控件没有业务意义。
- 该控件是仓库下拉在空选项状态下被可搜索下拉组件提前包装，之后动态加载仓库选项时产生的重复显示。
- 实施任务型抽屉时删除当前内联批量库存编辑区域，不保留该 `请选择`控件。
- 抽屉中不增加其他前置筛选项，直接展示仓库名称搜索和仓库多选列表。

### 头部

显示：

- 标题：`批量设置仓库库存`
- 已选 SKU 数
- 可修改 SKU 数
- 跳过的联动 SKU 数

当存在跳过项时显示提示：

> 本次只修改未开启库存联动的 SKU。已开启库存联动的 SKU 保持只读，不参与本次批量操作。

### 左侧：选择目标仓库

- 提供仓库名称搜索。
- 仓库名称搜索是唯一的仓库筛选入口。
- 仓库使用可滚动列表展示，不限制仓库数量。
- 支持同时选择多个仓库。
- 已选择仓库显示勾选状态和已选数量。
- 常用仓库可以显示轻量标记，但不改变操作规则。

### 右侧：分别设置库存数

- 每个已选仓库生成一行库存设置。
- 每行包含仓库名称、库存数字输入框和移除按钮。
- 库存只支持直接“设置为多少”，不提供增加或减少模式。
- 不同仓库允许填写不同库存数。
- 同一仓库填写的库存数统一应用到全部可修改 SKU。
- 库存必须为大于或等于 0 的整数。

示例：

```text
美国西仓：20
美国东仓：12
德国仓：8
```

若有 5 个可修改 SKU，则以上三条规则分别应用到这 5 个 SKU。

### 修改范围预览

提交前显示：

- 可修改 SKU 列表
- 已选仓库数量
- 总更新项数

计算方式：

```text
总更新项数 = 可修改 SKU 数 × 已填写库存的仓库数
```

示例：

```text
5 个 SKU × 3 个仓库，共更新 15 项库存
```

### 底部操作

- 次要按钮：`取消`
- 主要按钮：`确认更新 N 项库存`
- 未选择仓库、存在空值或存在非法库存值时，主要按钮禁用。

## 数据处理

打开抽屉时：

1. 读取当前勾选的 SKU。
2. 按 `stockLinked` 分为可修改 SKU 和跳过 SKU。
3. 只将可修改 SKU 传入批量库存任务。

提交时：

1. 校验至少选择一个仓库。
2. 校验每个已选仓库都填写了有效库存数。
3. 将每个仓库的库存数写入全部可修改 SKU 的 `warehouseStocks[warehouseId]`。
4. 不修改任何跳过 SKU。
5. 重新计算所有受影响 SKU 的 `可售合计`。
6. 关闭抽屉并刷新 SKU 表格。

## 操作反馈

### 成功

显示：

```text
已更新 5 个 SKU、3 个仓库，共 15 项库存
```

### 空状态

- 未选择仓库：提示 `请选择至少一个目标仓库`。
- 未选择可修改 SKU：不允许打开抽屉。
- 仓库搜索无结果：显示 `未找到匹配仓库`。

### 校验错误

- 库存为空：对应仓库行显示 `请输入库存数`。
- 库存小于 0：对应仓库行显示 `库存不能小于 0`。
- 库存不是整数：对应仓库行显示 `请输入整数库存`。

## 可访问性

- 抽屉打开后焦点进入标题区域，关闭后回到 `批量库存`按钮。
- 仓库选择项使用真实复选框或等效可访问控件。
- 库存输入框的可访问名称包含仓库名称。
- 错误信息与对应输入框关联。
- `Esc`关闭抽屉；存在未提交修改时需二次确认。

## 不在本次范围

- 库存系统同步。
- 在批量库存抽屉内开启或关闭库存联动。
- 库存增加或减少操作。
- 为不同 SKU 设置不同的批量库存值。
- 库存变更日志、权限、审批或真实 API。

## 验收标准

- 只有存在已选非联动 SKU 时，`批量库存`按钮可点击。
- 混合选择时只修改非联动 SKU，联动 SKU 保持不变。
- 支持搜索并同时选择多个仓库。
- 每个已选仓库可填写不同库存数。
- 库存只支持直接设置，不出现增加或减少选项。
- 提交前正确显示 SKU 数、仓库数和总更新项数。
- 提交后受影响 SKU 的仓库库存和可售合计即时更新。
- 仓库数量增加时，抽屉通过搜索和滚动列表扩展，不出现横向仓库矩阵。
