# 添加赠品页返回按钮设计

## 目标

将赠品管理的添加/编辑赠品页面顶部次要操作从 `取消` 改为 `返回`，并确保点击后始终回到赠品管理的 `赠品池` Tab。

## 适用范围

- 页面：`admin/gift/gift_pool_form.html`
- 交互逻辑：`admin/gift/js/gift_pool_form.js`
- 公共返回逻辑：`admin/gift/js/gift_common.js`
- 新增和编辑赠品共用同一表单，因此统一显示 `返回`
- 赠品规则表单不在本次改动范围

## 交互规则

- 按钮文案由 `取消` 改为 `返回`。
- 点击按钮后明确进入 `gift/gift.html?tab=pool`。
- 在后台主框架内打开时，继续通过 `loadAdminPage` 返回赠品管理并激活赠品池 Tab。
- 直接打开表单页面时，不使用 `history.back()`，改为显式跳转到赠品池 Tab，避免返回到无关页面或空白历史记录。
- 保存赠品后的返回行为保持不变，仍回到赠品池 Tab。

## 不在本次范围

- 不修改赠品规则表单按钮。
- 不调整赠品表单布局、样式或保存逻辑。
- 不引入来源页记录或浏览器会话状态。

## 验收标准

- 添加赠品页按钮显示为 `返回`。
- 编辑赠品页按钮显示为 `返回`。
- 在后台主框架中点击返回后，赠品管理页面的赠品池 Tab 处于激活状态。
- 直接访问表单页面后点击返回，也能进入赠品管理的赠品池 Tab。
