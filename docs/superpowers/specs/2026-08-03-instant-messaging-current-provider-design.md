# 即时通讯当前服务商页设计

## 目标

让运营者在进入配置页时立即知道当前服务商、验证状态和买家端展示状态；服务商的选择集中在一个轻量列表弹窗中，避免把连接、管理和启用混为一谈。

## 页面结构

1. 一级页面展示当前服务商摘要、当前服务商的连接配置、买家端展示与会话上下文。
2. `管理服务商` 打开单列表弹窗，支持搜索并明确展示：当前使用、已验证、待配置、即将支持。
3. 选择未配置的受支持服务商后，一级页面切换至该服务商并关闭买家端展示，直到配置验证成功。
4. 已验证服务商可切换为当前服务商；切换后仍要求运营者确认买家端展示开关，避免无意切换线上入口。

## 买家端规则

- 系统托管安装，不在此页复制或注入第三方脚本。
- 只有当前服务商已验证且“启用买家端展示”打开时，才会在买家端显示入口。
- 默认入口可以是全站悬浮入口或仅使用未来装修页的即时通讯区块；页面放置区块时，区块优先并隐藏该页悬浮入口，确保每页只有一个入口。
- 首页会传递页面来源；商品详情页的任何即时通讯入口会自动传递商品链接、主图、当前 SKU/变体、价格和可售状态。

## 原型边界

验证仅做本地字段完整性校验与本地保存；不调用第三方 API、不保存真实密钥、不加载第三方 SDK。
